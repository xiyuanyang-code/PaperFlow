# References

You can freely place any reusable document files here. Examples include:

- **Experiment report templates** — your preferred report format, section structure, and styling
- **Assignment requirement docs** — course LaTeX formatting requirements and submission guidelines
- **Personal writing preferences** — your preferred phrasing, common expressions, and layout habits
- **BibTeX reference libraries** — accumulated `.bib` files to avoid repeated lookups
- **Chart/table style guides** — your preferred color schemes, chart types, and table formats
- **Past well-written documents** — use as reference examples to maintain style consistency

The agent will check this directory when generating LaTeX documents and use the contents as reference to customize the output.
